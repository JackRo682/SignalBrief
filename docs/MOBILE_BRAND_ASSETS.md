# Mobile brand assets

The NVIDIA, Apple and Tesla SVG path data in `apps/web/src/mobile/brand-paths.ts`
comes from Simple Icons. The paths are unchanged; presentation uses each mark's
brand color within the existing company tile. This replaces enlarged 32-pixel
raster assets in the mobile UI.

Retrieved on 2026-10-06:

- NVIDIA: https://github.com/simple-icons/simple-icons/blob/develop/icons/nvidia.svg
- Apple: https://github.com/simple-icons/simple-icons/blob/develop/icons/apple.svg
- Tesla: https://github.com/simple-icons/simple-icons/blob/develop/icons/tesla.svg
- License: CC0 1.0 Universal, https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md

Brand names and trademarks identify the companies represented by authenticated
source data. No endorsement is implied. Other existing company assets and the
CSS Microsoft mark continue to use the repository's existing presentation.
