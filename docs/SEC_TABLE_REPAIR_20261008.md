# SEC 표·Inline XBRL 수정 및 검증

**전체 판정: FAIL — 실서비스 완료 조건 미충족.** 실제 코드와 오프라인 검증은 추가했지만 신규 유료 호출 승인을 받기 전이므로 AI 재실행·공시 1쌍·운영 승인·Today 브라우저 확인은 완료하지 않았다. 기존 DB·Storage·API 키 연결을 다시 만들지 않았다.

## 재현한 원인과 수정

기존 `normalized_text()`는 숨겨진 XBRL 자원과 표 셀 병합 구조를 제거했다. `validate_fact()`는 연속 인용문 하나에 지표·값·단위·기간·연결 범위가 있어야 하고 `bound_numeric_claim()`은 하나의 금액만 허용한다. 따라서 실제 Apple의 `Total net sales` 행은 숫자가 맞아도 별도 머리글의 단위와 기간을 증명하지 못한다. 이 실제 행이 기존 검증기에서 부분 지원으로 거부되는 회귀 테스트를 남겼다. 기존 모델의 89개 후보는 원래 저장되지 않아 과거 후보별 정확한 재실행은 불가능하다. 집계된 실패 사유와 원본 표 구조를 근거로 원인을 재현했다.

| 기존 문제 | 수정 |
|---|---|
| 원문과 다른 연속 인용 | 표의 원문 조각을 좌표와 함께 명시적으로 재구성. 연속 인용이라고 표시하지 않음 |
| 지표 누락 | 같은 행의 표시 이름과 허용된 US GAAP concept를 함께 대조 |
| 통화·단위 누락 | HTML의 `$`와 단위 설명, XBRL unit의 ISO4217 USD 및 scale 교차 확인 |
| 기간 누락 | 해당 열의 날짜/개월 수와 context의 시작일·종료일을 대조 |
| 다중 열 오류 | rowspan/colspan을 논리 격자로 확장하여 다중 행 머리글 연결 |
| 근거 일부만 지원 | 원본 바이트·해시·셀·context/unit를 다시 계산해 후보의 모든 필드 일치 요구. 누락·중복·변조는 차단 |

`sec-tables-v1`은 명시적으로 선택하는 파일럿 경로다. **현재 범위는 연결 손익계산서의 매출·영업이익**이다. Apple 원문의 756개 Inline XBRL 숫자 중 8개를 검증했고 748개는 범위 밖으로 별도 기록했다. 이를 전체 공시 분석 성공으로 표시하지 않는다. 기존 전체 문서 경로와 검증 규칙은 유지했다. 배당·CAPEX·주석·부문별 지표, 임의 taxonomy/통화/변환 형식, XBRL 없는 표까지 지원한다고 주장하지 않는다. 확인할 수 없는 형식은 실패한다.

원본 gzip/base64를 별도 parser version의 DB 청크에 보존하여 원문 저장소와 같은 SHA-256에 묶는다. 외부 모델은 필요한 셀과 머리글만 받는다. 원문 압축 해제는 4MB로 제한한다. 서버 승인 시 원문을 재파싱하고 필드·인용·범위의 완전성을 다시 검사한다. 기존 hosted SQL의 인용문 포함 조건도 충족하며 해당 SQL 조건은 바꾸지 않았다. 표시 인용에 원문 조각의 재구성임을 명시한다. 모델 후보는 실패한 후보까지 AI 실행 이력에 저장해 다음 오류를 재현할 수 있게 했다.

기간은 fiscal quarter를 calendar quarter로 임의 변환하지 않고 `시작일/종료일`로 저장한다. Decimal 증감 계산을 유지하고 6개월/9개월 누적을 분기 대비로 비교하지 않는다. 최신 문서 안의 비교 우선순위는 동일 기간 수정 → 인접 분기 → 전년 동기이며, 과거 비교 열이 현재 브리핑의 대표 변화가 되지 않도록 현재 종료 기간을 선택한다.

## 테스트와 미검증 구분

파서·변조·기간 비교 테스트 23건, 실제 SEC 바이트와 격리된 SQLite/API를 사용하는 파이프라인 테스트 4건을 추가했다. 후자의 모델 응답은 테스트 대역이며 실제 AI 성공률이 아니다. 로컬 API에서 관리자 승인 후 180일 범위 피드 노출, 반려 후 비노출, 일반 사용자 승인 거부, 감사 기록, 재처리 시 단일 이벤트·실행 유지, 잘못된 값/누락의 승인 거부를 확인했다. 오래된 5월 공시는 기본 30일 피드 범위 밖이므로 기본 Today 화면 노출과 같다고 표현하지 않는다.

기존 포함 백엔드 회귀: 294 passed / 37 skipped. 별도 폐기용 PostgreSQL이 필요한 37건은 로컬에서 실행하지 않았다. Ruff·컴파일·OpenAPI·웹 lint/typecheck 통과. 로컬 웹 단위/빌드는 기존 Windows native path 접근 오류로 실패하며 Linux CI 결과를 별도로 확인한다. `checks.json`에는 공개 가능한 요약만 보존하고 개인 경로나 토큰이 포함될 수 있는 원시 로그는 제출하지 않는다.

미검증: 수정 경로의 실제 AI 응답, 두 번째 공시, 공시 간 비교, hosted DB에서 새 결과의 승인, 실제 Today 브라우저, 별도 일반 사용자/사용자 간 격리의 대화형 검증, 독립 인간 검수. 운영 DB에서 파괴적인 테스트를 하지 않았다. 이전에 검증한 Google 로그인·반려 기능을 이번 수정의 재검증으로 중복 계산하지 않는다.
