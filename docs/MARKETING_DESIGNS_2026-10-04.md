# 공개 안내 화면 디자인 적용

2026-10-04 (Asia/Seoul). 기존 main c368eaadc8b3a4030c2d405a7f356c1bb85f9af9에 이어 사용자 첨부 디자인 6개를 적용했습니다.

첨부 HTML은 1055×1491 PNG 전체 화면과 동일한 좌표의 투명 링크를 포함했습니다. 실제 문구·카드·버튼을 React와 Next Link로 구현하고, PC의 두 열 소개 영역과 모바일의 한 열 카드 구성을 제공합니다. 출처 해시와 사용한 일러스트의 범위는 [source manifest](marketing-design/source-manifest.json)에 기록했습니다. 산 배너와 개인정보 일러스트만 WebP로 추출하여 전체 페이지 이미지를 내려받지 않습니다.

- `/about`, `/features`, `/sources`, `/pricing`, `/customers`, `/privacy`에 공통 상단 메뉴와 하단 안내 링크를 제공합니다. 메인 페이지에도 개인정보 링크를 추가했습니다.
- 화면 예시는 클릭과 화살표·Home·End 키로 전환할 수 있으며 실제 시세나 고객 데이터로 표시하지 않습니다. 기능 카드와 예시의 사용 버튼은 미로그인 상태에서 로그인, 로그인 상태에서 해당 기능으로 이동합니다.
- 개인정보의 6개 상세 안내는 native details로 펼쳐지고, 선택적 이용 통계와 계정 설정은 로그인 상태에 맞춰 연결됩니다. 현재 앱이 처리하는 정보와 기존 개인정보 안내의 제한을 유지했습니다.
- 공개 고객 사례는 준비 중이며, 예시 문구는 고객 후기와 구분합니다. 실제로 검증되지 않은 고객 수·커버리지·가용성 수치를 게시하지 않습니다. 무료 공개 베타와 결제 미연결 상태를 안내합니다.
- 원본 디자인의 문의 이메일과 응대 시간은 운영 사실이 확인되지 않아 문의 채널 준비 중으로 표시했습니다. 문의하기 버튼은 `/privacy#contact`로 이동합니다.

검증은 `scripts/verify.py --full`, desktop/mobile Playwright, reference browser, disposable PostgreSQL로 수행합니다. 새 공개 페이지 E2E에는 실제 링크 이동, 문서 유지, 미로그인·로그인 분기, 데모 키보드 조작, 개인정보 상세 펼치기, 이미지 로딩과 수평 넘침 검사가 포함됩니다. 현재 기능 CI에 `marketing-pages.spec.ts`를 추가했습니다. 기존 개발 도구의 braces 보안 경고를 숨기거나 감사 검사를 약화하지 않았습니다.

실행 결과: 전체 검증 8개 항목 통과(백엔드 243 통과·선택 PostgreSQL 2 건너뜀, 프론트 단위검사 187 통과), 실제 별도 PostgreSQL 2 통과, 데스크톱·모바일 E2E 24 통과, reference browser 74 통과. 가입·복구 요청은 합성 Auth 응답을 사용하는 검사이며 실제 메일 발송이나 Google 계정 동의를 수행하지 않습니다.
