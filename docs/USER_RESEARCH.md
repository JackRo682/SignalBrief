# Source audit / user research limitation

The available source is `붙여넣은 마크다운.md`, archived unchanged as SOURCE_REQUEST.md. It contains the SignalBrief mission,
MVP, engineering prompts and descriptions of a purported 105-person survey. The original survey PDF and original Product Vision
were not independently available in this fresh-task attachment set. They were not retrieved from prior projects or memory.

Therefore this implementation uses the explicit product requirements in the markdown and does not treat its second-hand survey
numbers as independently verified raw research. No segmentation, statistical significance, willingness-to-pay result or actual
interview observation is invented. Source-confirmed requirements and implementation assumptions are separated in PRD.md.

Before product validation, supply the actual survey file and sampling/question metadata under an explicit new task. That is not a
prerequisite for running the synthetic code demo, but it is necessary to claim data-backed survey conclusions.
