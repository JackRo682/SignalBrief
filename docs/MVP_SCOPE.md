# MVP scope

P0: official-document provenance, watch/portfolio membership, strict extraction, explicit changes, citations, relevant briefs,
user separation, review gating, tests. P1: timelines, extractive follow-up, manual/sourced calendar, in-app alerts, operational queues,
consent telemetry and an evaluation harness. P2: broader parsed-format coverage, independently calibrated semantics/ranking,
real-world expert Gold Dataset and market data integrations only after licensing/provider design.
Not now: generic news, trading, buy/sell recommendations, target price generation, payment gateway and native mobile app.

All MVP screen categories in the supplied markdown have source implementations. The qualification is testing and conservative
behavior depth, not an invented claim that external integrations and production operations are already verified.
