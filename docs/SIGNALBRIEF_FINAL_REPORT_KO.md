# SignalBrief 독립 소스 검증 결과

검증일: 2026-10-02. 이번에 제공된 독립 소스만 사용했으며 과거 프로젝트, 저장소, 배포 및 자격 증명을 참조하지 않았습니다.

## 실제 검증

- 전체 백엔드: 238개 통과, 실패·건너뜀 0개. SQLite 및 새 일회용 PostgreSQL 마이그레이션/RLS 검사 포함.
- 증거 회귀: 86개 통과. 근거: `verification/quarter-regressions.log`. 기존 `adversarial-tests.log`의 75개 결과는 이전 실행 기록입니다.
- Ruff, OpenAPI, ESLint, TypeScript, Next 빌드 통과. 프런트엔드 단위 테스트 19개 통과.
- 최종 소스의 데스크톱·모바일 Playwright 각각 3개 통과. 로그인, 온보딩, 관심종목, 변경사항, 상세/전후 증거, 질문, 알림, 반복 이동, 로그아웃과 권한 분리를 확인했습니다.
- 합성 평가 120개 통과. 실제 금융 정확도나 사람 검증 정답 데이터셋의 성능을 의미하지 않습니다.
- Vitest/@vitest/mocker 4.1.11, Vite 7.3.6으로 수정했고 npm audit 취약점은 0개입니다.
- 명령문 커버리지 79.12%. 작업 완성률이 아닙니다.

## 수정 사항

지표·값·단위·기간을 보수적으로 결합하며, Q1/Q2 및 영문 분기명도 지표/값 절에 속해야 합니다. 불명확하거나 인식하지 못한 기간은 보류합니다. 단위 배율을 정규화하여 충돌을 판단하고, 과거 증거를 다시 검증합니다. 반려된 조상과 superseded 중간 버전을 포함한 전체 수정 이력을 순회하여 게시를 차단합니다. 관리자의 강제 승인도 409로 거부합니다. 자동 게시는 false로 유지했습니다.

## 운영 준비와 차단 사항

Supabase 프로젝트·JWT/JWKS·관리자 UUID·DB, Google OAuth 콜백, 비공개 영속 원문 버킷, DART 키/범위/할당량, SEC 연락처 User-Agent, OpenAI 키/실제 모델/예산, Vercel·Render 배포 및 비용·비밀 등록 권한이 필요합니다. 전체 설정은 `docs/CURRENT_SETUP_AND_BLOCKERS.md`에 모았습니다. 비밀은 서버에만 등록하며 NEXT_PUBLIC에는 공개 설정만 둡니다.

외부 수집·OAuth·원문 복구·실제 모델·사람 정답 검증과 배포는 아직 차단 상태입니다. PDF/OCR, 대용량 문서, 자유 형식 의미 추론, 개인정보/보존정책과 부하·장애·복구 검증도 미완료입니다. Docker가 없어 컨테이너 검증은 수행하지 못했습니다. RLS 결과는 선택된 로컬 동작 검사이며 모든 운영 테이블/동작 검증을 뜻하지 않습니다.

공개 데모나 유료 자원을 만들지 않았고 배포·push·merge도 하지 않았습니다. 브라우저 검사는 127.0.0.1에서만 실행했으며 검사 후 서버를 종료했습니다. 전체 소스 ZIP에는 실제 lockfile, 변경 파일 목록, 명령과 원본/새 검증 로그를 포함합니다.
